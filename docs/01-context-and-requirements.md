# 01 · 背景、需求与关键决策

## 1. 背景

用户手上有电路图（原理图），希望借助 AI 完成后续工作。最初的诉求很直接：

> “你能否准确识别电路图？如果不可以，我把电路图给你，你能转换成你能精确理解的图或者结构吗？”

这是一个**能力边界问询**，而不是单纯的工具请求。因此第一步的工作是**诚实说明能力边界**，而不是直接承诺“我能识别”。

## 2. 需求演进（三轮）

| 轮次 | 用户提出 | 实质需求 |
|---|---|---|
| R1 | 能否准确识别电路图？不能的话能否转成我精确理解的结构？ | 明确能力边界；确定一种**可靠的信息传递格式** |
| R2 | 能否把图片转成 HTML 网页、我核对、不正确我能编辑电路图并保存；网页要提供修改电路图的基础功能模块。可行吗？有没有更好的方案？ | 从“一次识别”升级为**人机协同的复核闭环**；要求可编辑 + 可持久化 |
| R3 | 是否有开源方案？ | 避免重复造轮子；判断自研边界 |

已确认的选择：
- 图纸形式：**截图 / 照片 / 扫描件（位图）**（不是 PDF，也没有 EDA 源文件）
- 目标用途：**看懂拓扑 + 找出可疑点**（不是 PCB 生产、不是仿真精度）

## 3. 硬约束

| 约束 | 说明 |
|---|---|
| 准确性 | 引脚号 / 网络名 / 阻容值 单点错误会让后续所有结论失效 |
| 可复核 | 每条结论必须能追溯到“由谁确认过”，AI 判断与人判断必须可区分 |
| 可编辑 | 认错的地方要能在网页上直接改，不能要求重画整张图 |
| 可持久化 | 改完能保存、能导出、下次能继续（不能只存在内存里） |
| 可下游使用 | 导出必须是**结构化数据**，能喂给后续分析/验证链路 |
| 隐私 | 图纸可能含内部信息，工具应**纯本地离线**，不上传云端 |

## 4. 关键决策

### D1 · 不承诺“准确识别位图”
视觉模型能看图，但**不能保证工程级准确**。硬伤：引脚编号、交叉 vs 连接、总线分线、跨页连接符、参数值。
→ 因此**位图识别只产出 draft**，且**每条连接带置信度**。

### D2 · 目标不是“识别”，而是“降低纠错成本”
把 KPI 从“识别准确率”换成：
- 认错一处要几次点击能改对
- 改完之后，后续分析与原图是否一致可验证
- 有没有留痕（谁在哪一步确认了什么）

### D3 · 连通性由几何推导，而不是存在数据库里
如果让用户直接编辑“网络成员列表”，画布与数据必然脱节。
→ 数据源 = 几何（元件 / 导线 / 连接点 / 标签），网络是**推导结果**。
→ 唯一的例外是 `disconnected`（标记某引脚不连接）和 `linked`（虚拟连接），因为这两类事实**无法用几何表达**，必须显式声明。

### D4 · 十字交叉必须显式判定
原理图里“交叉”有两种含义（相连 / 不相连），这是位图识别最高频的错误来源。
→ 规则：**十字交叉默认不导通**，只有存在 junction 才导通；未加 junction 的交叉报 `E11`。

### D5 · 虚拟连接：不画假线
识别时经常出现“原图上确实没画线，但两侧逻辑相连”（跨页连接符、总线入口、图纸省略）。
→ 用**紫色虚线 + 显式 link 记录**表达，而不是画一根不存在的导线。导出时单列。

### D6 · 状态化复核（可审计）
引脚级 `checked` 是唯一事实，网络状态由成员聚合。导出带 `review` 统计。
→ 这样“AI 草稿”和“人工确认”在数据层面天然可区分，不会混为一谈。

### D7 · 单文件离线前端，不引入构建链
原型要求“双击就能用、无网络、无后端”。
→ 纯原生 JS + SVG，无框架、无构建、无依赖；`localStorage` 持久化，`Blob` 下载导出。

### D8 · 后端格式优先对齐开源生态
不发明私有格式作为终点。最终交换格式指向 **KiCad**（文本、生态好、可网页渲染、有 ERC 与 CLI）。
→ 当前 JSON 是中间态，已预留映射路径（见 [04-plan.md](04-plan.md)）。

## 5. 验收标准（v0.1）

- [x] 双击打开即用，无依赖、无网络
- [x] 可载入原图并与画布元件建立定位关联
- [x] 可编辑元件/导线/连接点/标签，改动即时反映到网表
- [x] 网表视图可逐条核对，能标记“不连接”、能命名网络
- [x] 复核状态可确认，画布上状态可视
- [x] ERC 覆盖悬空、单点、命名冲突、电源域、驱动冲突、交叉未连接
- [x] 可导出结构化网表 JSON + 人工可读 Markdown + SVG/PNG
- [x] 内置自检 25 项全通过
