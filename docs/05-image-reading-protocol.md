# 05 · 位图读图协议

> 位图（截图 / 照片 / 扫描件）是本项目输入中**最不可靠**的一类。
> 本协议的唯一目的：把人工可提供的额外信息（分块、缩放、清单）榨干，尽量抬高识别质量。

## 1. 文件命名约定

```
page1_full.png          整页概览（先给，用来定位与分块）
page1_A.png             左上块（200% 以上放大）
page1_B.png             右上块
page1_C.png             左下块
page1_D.png             右下块
```

## 2. 图片质量红线

| 项 | 要求 |
|---|---|
| 来源 | 优先 PDF 页直接导出/截图，**不要拍屏幕**（摩尔纹会毁掉文字） |
| 分辨率 | 单块图片短边 ≥ 1200 px；文字高度 ≥ 12 px |
| 缩放 | 截图时放大到 200%～400%，保证 refdes 与 net label 可读 |
| 分块 | 先整页一张，再按 2×2 或 3×2 切块分别给 |
| 姿态 | 正向；不要斜拍、不要透视变形 |
| 遮挡 | 不要带水印、鼠标指针、遮罩框 |

## 3. 能提供就提供（显著提升准确率）

- **可复制文字的 PDF**（优先于任何截图）
- **参考位号清单 / BOM**：`U1, R12, C5 ...` —— 有了它就能“反查”而不是“硬认”
- **网络名清单**：`KL30, GND, CAN_H ...`
- **页间连接关系**：哪张图接哪张，跨页连接符叫什么名字
- **供电域与接地符号说明**：不同厂商画法差异极大，提前说明能省一轮确认

## 4. 输出约定

| 产物 | 内容 |
|---|---|
| `01_netlist.json` | 结构：components / pins / nets |
| `02_topology.md` | 拓扑说明 + Mermaid 图 |
| `03_uncertain.md` | **低置信点清单**：哪些字/线没把握，需人工确认 |
| `04_findings.md` | 可疑点：悬空、单点网、上下拉缺失、电源域混接、驱动冲突等 |

## 5. 铁律

- 位图识别结果**一律标记为 draft**
- 每条连接带置信度：`high / medium / low`
- **`low` 项不参与任何验证结论**，必须先由人工确认或对照原图复核
- 确认动作发生在 `app/` 工作台里，并留下 `pinChecked` 痕迹（可审计）

## 6. 推荐复核顺序

1. **电源与地**：先确认所有 `VCC/GND` 符号及其网络名（最快形成锚点，也最容易合并全局网络）
2. **主信号链**：从输入连接器 → 保护/滤波 → 主芯片 → 输出级
3. **交叉点**：专门过一遍 `E11` 列出的“十字交叉未加连接点”，逐点确认
4. **未命名网络**：给 `N_*` 起有意义的名字（命名即语义，便于后续分析）
5. **悬空引脚**：确认是真的 NC，还是漏了连线（`×` 标记 vs 补线）
